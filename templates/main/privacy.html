Версия политики: {{ PRIVACY_VERSION }}. Версия согласия: {{ CONSENT_VERSION }}.

Какие данные собираются

Через формы сайта могут передаваться имя или компания, телефон, email, комментарий к заявке, выбранные позиции каталога и приложенные файлы спецификации.

Для чего используются данные

Данные используются для обработки запроса, подготовки ответа по заявке, подбора материалов, оборудования, производителей и аналогов под спецификацию, сроки и бюджет.

Файлы

Файлы используются только для обработки заявки. Не загружайте паспорта, медицинские данные, биометрию и чужие персональные данные без законного основания.

Текущий технический срок хранения загруженных файлов: {{ FILE_RETENTION_DAYS }} дней. Для удаления реализована серверная команда очистки, которую нужно подключить к регламентному запуску на production.

Cookie, технические данные и веб-аналитика

Сайт использует необходимые cookie и технические данные для работы интерфейса и защиты форм. Необязательная аналитика и маркетинговые инструменты могут включаться только после согласия пользователя.

При выборе в cookie-баннере сохраняется значение выбора, версия текста, дата, адрес страницы, IP-адрес и User-Agent для подтверждения факта выбора.
