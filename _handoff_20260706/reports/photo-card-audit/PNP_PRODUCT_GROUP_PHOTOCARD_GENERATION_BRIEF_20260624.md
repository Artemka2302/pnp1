# Бриф на догенерацию фотокарточек товарных групп PNP

## Зачем нужен этот файл

Аудит ищет не просто отсутствующие файлы, а видимые дубли внутри страниц систем. Если несколько товарных групп используют одну fallback-фотокарточку системы, на сайте это выглядит как повтор одной и той же карточки. Такие позиции нужно закрывать отдельными изображениями.

## Итог аудита

- Всего товарных групп в `catalog_master.json`: 235
- С отдельной фотокарточкой: 235
- Без отдельной фотокарточки: 0
- Систем с видимыми дублями внутри одной страницы: 0
- P0/P1 карточек для генерации в первую очередь: 0
- P2 карточек для полной уникализации позже: 0

## Общий стиль генерации

- 1200 x 900, 4:3, WEBP/PNG.
- Премиальная тёмная фотокарточка PNP: графит, стекло, металл, бордовые акценты, реалистичный свет.
- Без текста, логотипов, водяных знаков, крупных людей на переднем плане и случайных надписей.
- В одной системе соседние карточки должны отличаться предметом и композицией.
